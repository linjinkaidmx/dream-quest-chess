# 梦境征途 · 冒险策略棋

单人闯关的策略博弈小游戏：**先走到对岸者胜，路上可以放墙封路**。
7 章 100 关，棋盘随章节从 7×7 长到 13×11，AI 强度逐章爬升。
全程 WebAudio 合成音效与 BGM（零音频文件，保住单文件架构）。

## 在线游玩（手机 / 微信浏览器均可直接打开）

**https://dream-quest-chess.app.workbuddy.host**

HTTPS 站点，无需安装、无需登录；手机浏览器和微信内置浏览器都能直接点开。
入口是 `index.html` 游戏本体；目录内其余文件（测试脚本、截图、文档）虽随包上传但玩家只会访问到游戏页。

## 本地游玩

双击 `index.html` 即可（推荐 Chrome / Edge）。纯单文件、零外部依赖、不需要联网、不需要后端。

## 玩法

- **走子**：点亮着的发光格子，球会滚过去（每回合走一格，上下左右）
- **筑墙（两种手势任选）**：
  - **点两下**：点格线**交点** → 四个方向亮出候选墙影（合法金 / 非法红）→ 再点一下落墙
  - **拖拽**：按住交点 → 拖满 2 格 → 松手放下（横拖竖拖决定墙的方向，可以往两边拖）
  - **出手前预警**：落不了的墙直接显示红色 + 原因（"会把金球封死"/"会和别的墙相交"），不再事后弹 toast
- **胜负**：先到达对方那一侧**整条边线**的人获胜（不是某一格，走任意列都算）
- **铁律**：墙不能把任何一方彻底封死——落墙后双方都还必须能到达终点，否则不允许落下
- **其他**：双方各 10 面墙；两个球不能重叠；墙用完就只能走格子
- **星级**：按 par 步数评定（≤par 三星，多 2 步内二星，其余一星）
- **进度**：自动存在浏览器本地（localStorage），换设备不同步

## 关卡玩法（每章 15 关混编）

| 玩法 | 布局 | 说明 |
|---|---|---|
| 相向竞速 | 两人各守一侧 | 经典：先到对岸者胜 |
| 门关 | 起点在对角 | 只有中央那扇门算终点，其余位置不算 |
| 同向竞速 | 并排从同一侧出发 | 抢同一条终点线，挡在对手前面比抢速度更管用 |
| 共同终点 | 起点在两侧、目标相同 | 不同起点抢同一扇门，谁先站上谁赢 |
| **追逐** | 怪物守在棋盘中央 | 它与你**同速但会拦截**：奔向你到对岸最短路的半程点，抢在你前面堵路。它贴上身（回合结束时相邻）就会扑上来。**墙是唯一能改变它路线的手段**——把它的拦截路线堵开，甩开它冲到对岸 |
| 回廊迷宫 | 地形 | 每隔几行一道隔断、缺口左右交替，强制蛇形绕行 |

每章配比：7 经典 + 2 门型 + 2 迷宫 + 1 同向 + 1 共同终点 + 1 追逐 + 1 Boss；第 1 章前 5 关保持纯教学（空盘经典）。

### 追逐关的三条铁律（2026-09 重做）

1. **怪物与你同速（每回合 1 格），但会拦截**——它抢的是"半程点"（`CHASE_CUT`，当前 0.48）。旧版"每回合 2 格直追"实测非黑即白（要么碾压要么被碾压），已废弃
2. **抓捕规则 = 象棋"将军"**：你一回合结束时若与怪物相邻，它直接扑上。被贴住就必须立刻甩开，被逼进墙角甩不开就输了
3. **落墙必须保证怪物仍能走到你当前位置**——否则玩家一堵墙就能把它永久隔离
4. **量化验收（写进 `_test.js`）**：会放墙的打法 7 关全胜（可解）；不放墙的直线跑只能赢少数关（≤3/7，墙是唯一手段）——这就是"技巧空间"的存在证明

两种终点画法（引擎判定与画面严格一致）：

- **整条边线**：色带 + 斜纹 + 沿线插满小旗 → 任意一格都算
- **门型**：只把指定格画成一扇带「门」字的拱门 → 其余位置一点终点痕迹都没有

配套的可读性设计：进关前 HUD 有一行「**目标 XX**」；世界地图的关卡节点带玩法角标（门/箭头/回廊），能一眼挑出想玩的类型。

## 特殊格（五种机关）

数据在 `level.specialCells`，编排在 `SPECIAL_PLAN`：第 2~6 章各两关（首秀 + 进阶），外加最后一章的 Boss「天空之门」用传送门做文章。

| 机关 | 效果 | 注意 |
|---|---|---|
| **传送门** | 踩上立刻传到配对的那扇（一上一下配成对） | 横跨半个棋盘抢位 |
| **加速带** | 踩上沿原方向再滑一格 | 滑行**不能穿墙**；落点不可站就停在原地 |
| **弹簧** | 踩上沿原方向弹两格 | **能越过墙与障碍**——这是唯一能越墙的手段；落点不可站就退成一格 |
| **陷阱** | 踩上丢 2 面墙 | 常放在捷径上，绕开还是硬踩由你决定 |
| **拆墙器** | 踩上立刻多 1 面墙 | 常在必经之路旁边——绕开还是顺路捡由你决定；编辑器画笔「6」，分享码兼容 |

设计底线（都有断言守着）：

- **机关只提供"更快/更省"的可能，不是唯一解**：把机关全部拿掉，关卡仍是一盘能正常分出胜负的棋
- **机关不会添乱**：带机关时玩家的回合数不会比不带更多
- **机关不改变棋盘连通性** → 墙的合法性判断不受影响
- 机关只落在**中线**附近（双方都可能经过，谁先占谁占便宜），且绝不压在障碍、起点、终点上

## 教学系统（每个新机制首次出现都讲一次）

不是只讲前三关：**任何新规则/机制第一次出现时，进关前都会弹一张教学卡**——一张带轻微动画的示意图 + 两三行话把规则说清，看过就不再打扰（记在本地）。

覆盖面：门关、回廊迷宫、同向竞速、共同终点、**追逐**、章末 Boss（含该关的关卡机制：岩浆收缩 / 门漂移 / 阶段切换）、**双人对战**（首次切双人时弹）。

示意图都是一张迷你棋盘 + 只突出一个变量：怪物逼近、岩浆从两侧挤、缺口左右交替、两个球轮流高亮……动画只做"让人看懂方向"这一件事，不堆特效。**新增机制时只需在 `introArt()` / `MECH` 里加一条，教学流程会自动带上。**

## 章末 Boss（每章最后一关）

Boss 一律遵守一条：**只突出一个新变量**，一句话说得清；进关前有一张 Boss 卡（名号 + 机制 + 对手打法 + 克制提示），地图上是金环加王冠。

| 关 | Boss | 机制 | 对手打法 | 实现方式 |
|---|---|---|---|---|
| 15 | 林间守卫 | 门关 + 回廊迷宫 | 竞速型 | 纯数据 |
| 30 | 雾中双生 | 左右各一扇门，都算终点 | 镜像型 | 纯数据 |
| 45 | 风墙试炼 | 双方各 20 面墙 + 迷宫 | 筑墙型 | 纯数据 |
| 60 | 城堡守卫 | 开局就有 14 面预置墙 | 埋伏型 | 纯数据 |
| 75 | 熔岩收缩 | 每 3 回合两侧各塌 2 列 | 冲锋型 | 回合事件 `shrink` |
| 90 | 天空之门 | 每 3 回合门换位置 | 镜像型 | 回合事件 `shiftGate` |
| 100 | 星夜终局 | 三阶段：冲锋 → 筑墙 → 镜像 | 轮换 | 回合事件 `phase` |

**回合事件**是这一批最重要的基础设施（`level.events`，每回合 tick 一次）：
`shrink`（棋盘收缩）· `shiftGate`（终点漂移）· `phase`（切换 AI 人设）。
它还顺手开出后续玩法：定期落障、怪物加速、限时关都挂在这上面。

**AI 人设库**（`PERSONAS`，同一套评估框架换权重与取向）：

| 人设 | 行为 | 关键参数 |
|---|---|---|
| 竞速型 race | 攻守均衡 | 标准权重 |
| 冲锋型 charger | 只顾冲刺，极少放墙 | 墙代价 ×6 |
| 筑墙型 builder | 拼命堆墙堵你 | 墙代价 ×0.35，允许只推 1 格也放 |
| 镜像型 mirror | 贴着你的列走 | 打分改为「缩短与你的横向距离」 |
| 埋伏型 ambusher | 前期先布墙 | 墙代价 ×0.5 |

两条安全约束（防止 AI「看起来凶、其实自残」）：**只放真能推开对手且不拖慢自己的墙**；**绝不落一手会把自己封死的墙**。

## 双人对战（同屏轮流）

地图首页有「**双人对战**」按钮，进关后 HUD 上也能用「双人 / 单人」随时切换（切换会重开本局）。

- 两人一台设备轮流走：金球与紫球**各 10 面墙**，谁先到对方那条边谁赢
- HUD 会写明「**轮到 金球 / 紫球**」，底部提示同步显示本方剩余墙数，双方目标也分别标出（金球→顶边、紫球→底边）
- 结算显示回合数、用时与「**总比分**」（本地累计），可一键「再来一局」或「**交换先后手**」
- 双人局**不进单人存档**，不污染星级与进度；只有两回合（双方各走一手）才计 1 回合
- 双人时 AI 完全不参与（没有 420ms 延迟，走完立刻换手）

> 更远的「各自手机实时联机」已按你的意思挂起：它需要服务端 + 加密连接（wss），而 wss 必须配域名；Cloudflare 的默认域名在国内被 DNS 污染，所以要么买域名（¥50~100/年，不需要备案），要么用自己的服务器（需备案 1~3 周）。等你说服务器就绪我再接。

## AI 强度曲线

一局结束后有三个出口：**再次挑战**、**下一关**、**回到主界面**（最后一关时「下一关」直接变成「回到主界面」）。

AI 按关卡分档，参数全部在 `buildLevels()` 里数据化（`aiConfig`）：

| 关卡 | 档位 | 行为 |
|---|---|---|
| 1–5 | 新手档 | 只沿最短路推进、约 22–30% 的回合走错一步、**完全不放墙** |
| 6–20 | 起步 | 换成评估式 AI（会堵前路），但仍会犯错、决策带噪声 |
| 20+ | 熟练 | 不再犯错 |
| 40+ | 强 | 决策不再随机，每回合都取最优动作 |
| 60–100 | 拉满 | 墙的代价压到最低，最爱封路 |

两条策略约束（防止 AI「看起来凶、其实在自残」）：

- 只放**真能把对手推开 ≥2 格、且不拖慢自己**的墙——否则会为了堵远处对手把自己关进绕路里
- 被围到无路可走但手上还有墙时，把墙用在最拖住对手的地方，而不是空过一回合

墙数与玩家持平（新手关更少、后段双方都是 10 面）：难度靠决策质量拉开，不靠多给对手资源。

调参入口（`buildLevels()` 内）：`mistake`（犯错率）、`noise`（在前几名里随机挑，0 = 永远选最优）、`wallCost`（放墙代价，越低越爱放墙）、`budget`（墙数）。

想看量化强度：`node _ai_meter.cjs` 会打印每关「AI 对直线竞速对手」的胜负与放墙数，以及镜像对局（双方同强度互相打）的结果。
参考数据（对不放墙的直线竞速对手）：1–5 关玩家 6 回合取胜且 AI 零放墙；30 关起 AI 反杀；第 100 关连打 5 次全胜。

## 难度与失败统计（本地）

每次单人结算都会记一笔（双人局不算）：挑战次数、胜负、最少步数、平均步数、平均用墙。

- 「**我的**」页新增一张 **难度热力图**：7 行 100 格，颜色 = 失败率（未挑战 / 顺利 / 有点难 / 卡住 / 反复失败），顶部汇总"共挑战 N 次、失败 M 次、最难的第 X 关"
- 点任意格子展开该关的**战绩卡**（次数、胜负、最少步数、平均步数/墙数 + 一句可执行建议 + 一键再挑战）
- **失败面板会给出针对性建议**，按失败原因分流（被抢先 / 被围死 / 僵局 / 被怪物追上）并结合关卡机制（追逐 / 门型 / 迷宫 / Boss），累计失败 3 次以上还会点出"这关你已挑战 N 次"

数据存在本地 `dreamquest.stats.v1`，与星级存档分开，互不影响。

### 调平衡的机器：`node _meta.cjs`

让 5 种人设**两两对打**（先手/后手各半、跨多张图、双方都关掉随机性），输出胜率矩阵 + 总战绩。这比人肉试关高效得多——比如它当场发现"镜像型"因为把"贴列"的权重压过了推进，胜率只有 26.6%，调完权重后回到 55%（其他人设 41%~53%），再没有谁是无敌或废柴。引擎测试里也放了一个精简版（每种人设都必须赢过、且胜率不得高于 80%）。

## 关卡编辑器 + 分享码

地图首页有「**造一关**」按钮，「我的」页也有入口（还会显示已造了几关）。

- **10 种画笔**：障碍 / 橡皮 / 我方起点 / 对手起点 / 我方目标 / 对手目标 / 传送门（点两格成对）/ 加速带 / 弹簧 / 陷阱
- **可选玩法**（相向竞速 / 门关 / 同向 / 共同终点 / 追逐）与**对手档位**（轻松 / 普通 / 困难 / 拉满），换玩法会自动摆好起点与目标
- **实时体检**：堵死了路会直接说"有一方到不了目标"，起点压在障碍上也会点出来；体检不过就不让试玩
- **一键试玩**，画完直接开一局
- **分享码**：一条链接（例：`…#/c/1r9x911_.......A._…_0304_8384`）。对方点开就进对局，不走服务器——码里就是那张图
- **「我造的关」** 存在本地，可继续编辑 / 试玩 / 再复制链接

### 码的格式（可读、可手改）

`1<玩法 r/g/s/c/h><宽>x<高><对手档 0-3>_<网格每行>_<墙>_<我方目标>_<对手目标>`

- 网格字符：`.` 空 · `*` 障碍 · `P` 我方起点 · `A` 对手起点 · `1`/`2` 传送门 · `3` 加速带 · `4` 弹簧 · `5` 陷阱
- 目标与墙**单独成段**（每格 2 个、每面墙 3 个 base36 字符）——因为一个格子可能既是目标又是别人的起点（相向竞速里对手起点就在我方目标行上），塞进同一张网格会互相覆盖
- 一张 9×9 的图约 95 字符，最长的 13×11 图也不到 400 字符，能直接发微信
- 解码后会做完整性校验（尺寸、起点、目标、传送门成对、**双方可达**），不合法就显示"这张分享码打不开"并说清怎么办，而不是白屏

自定义关**不进主线存档与难度统计**，结算面板也给的是「再玩一次 / 回到编辑器 / 分享这张图」。

## 技能卡

**不是"开局选卡"，而是"本关随时用一张"**——不打断节奏，还多了临场应变的余地。HUD 上有个「技能」按钮（可点时是金色高亮），点开就是七张卡：

| 卡 | 效果 | 解锁 |
|---|---|---|
| **备墙** ＋ | 立刻多带 2 面墙（墙不够时的救命牌） | 开局 |
| **拆墙** − | 对手本关少 1 面墙 | 开局 |
| **预知** 眼 | 本关随时看到对手的**最佳选择**——它打算走哪格、想封哪面墙（红虚线圈出来） | 开局 |
| **侦察** 图 | 本关画出对手到目标的最短路（紫色虚线，用来判断该在哪堵） | 开局 |
| **二连走** ⇉ | 本关的一次走子可以直走 2 格（路径不能有墙和障碍，蓄力后走位提示里会出现紫色虚线环） | 第 2 章 |
| **回响** 听 | 本关标出对手的行动焦点：追逐关是**怪物的拦截点**（红圈实时跳动），其他关是它的推进路线 | 第 4 章 |
| **撬棍** 撬 | 拆掉场上任意一面已有的墙（选卡后点那面墙即可） | 第 6 章 |

**"变强曲线"的主轴**：四张基础卡开局就有，三张进阶卡随章节解锁——让第 60 关的手和第 1 关的手不一样。解锁只看主线进度最远到过哪一章（自定义/每日关不计），进度保留的老玩家不会丢卡。

规矩很简单：**每关只能用一张，选中立刻生效，本关内持续有效**。用过之后按钮会写成「已用 · 预知」，再点会告诉你"每关只能带一张"。

三个细节：

- **预知是"问一次 AI"，不是"猜"**：临时把随机性关掉问一次，所以给的是"对手最想做什么"（措辞上也写"最佳选择"，不承诺它一定这么走）。问完立刻恢复，**不改动任何对局状态**（有断言守着）
- **双人同屏不给用**：两边都是人，给一方技能就失衡了，所以双人模式下这个按钮直接不出现
- 用没用技能会记进本地统计（`lastSkill`），给后面的「不用技能通关」这类成就留了钩子；胜利面板也会写明"本关用了技能卡：预知"

## 成就与外观

## 每日挑战

地图页顶部一张卡片：**今天的日期 · 今天是什么玩法 · 普通还是地狱打没打过**。

- **双档自选**：**普通档**（对手"强而不狠"、障碍 3~6 颗、事件更稀——会放墙的玩家目标胜率 ~50%，保底能赢）+ **地狱档**（对手拉满、障碍 6~10 颗——给会玩的人准备的）。两档玩法相同、棋盘略有不同
- **同一天，同一档，所有人拿到的是同一张图**——纯前端实现：`日期+档位 → 种子 → 同一套生成器`（不需要服务器）
- 每天自动换：棋盘 9×9 ~ 13×11、玩法在相向竞速 / 门关 / 同向 / 共同终点之间轮换、近一半的日子带一种机关、部分日子带回合事件
- **每天都保证能玩**：生成时逐颗校验障碍（不许把谁堵死）、过 `levelValid`、再要求"最短路落在合理区间"（太短没意思、太长太拖），不满足就换种子重来（最多 60 次）
- **连续天数**：今天任一档通关过就从今天数、没打就从昨天数，普通/地狱都算；两档分别留最好成绩（跨月跨年都算得对）
- 结算有自己的面板（档位 / 连续 N 天 / 今日步数 / 累计完成多少天），**不占主线星级、不进难度热力图**
- 两条成就挂在它上面：「今日已阅」完成一次、「坚持一周」连续 7 天

### 难度：两把尺子量过（写入 `_test.js`）

用同一批日期种子、两档各跑 6 天：

- **地狱档**：不放墙的玩家几乎全灭（≤2/6）；会放墙的玩家有胜算但不该全胜——"很难但可解"
- **普通档**：会放墙的玩家赢下多数（≥3/6），且明显强于不放墙的——"该赢能赢，技能有用"

### 已知取舍：追逐模式为什么不进每日

追逐关重做后（同速拦截）技巧空间已经量化验证（见上），但它的节奏与"每天 3 分钟"的每日形态还不合拍：一局要边跑边拆拦截，步数波动大。**主线 7 个追逐关已全部重做并回归**，每日挑战等观察一轮玩家反馈再考虑放入。
